# maxpowerart.github.io

Source of <https://kwasoftware.org/> (GitHub Pages, custom domain in `CNAME`; the old
`https://maxpowerart.github.io/` address redirects there): the catalog of my apps, plus pages that
apps link to.

| Path | What |
|---|---|
| `/` | App catalog: open-source (Kwalendar, GitKwaken, ekwalizer) and closed-source (KwanimeGo) apps |
| `/KwanimeGo-policy/` | KwanimeGo website, privacy policy and terms (linked from its Google OAuth consent screen) |
| `/Kwalendar/` | Served from the [Kwalendar](https://github.com/maxpowerart/Kwalendar) repository (`docs/`) |

The domain `kwasoftware.org` is verified in Google Search Console (DNS TXT record), as the apps'
Google OAuth consent screens require. The root page also keeps the Search Console HTML tag.
